# Security

Use downloads from Lane's official download page and this repository. Never share passwords, authentication tokens, marketplace cookies, wallet secrets or recovery phrases with support.

Lane Desktop separates local marketplace sessions from the Lane account. A computer already controlled by another person or malicious software cannot be made safe by app encryption alone.

There has been no independent security audit. For a suspected issue, consult [Lane Contact](https://lane-staging.onrender.com/contact) for the current private reporting route. Do not disclose exploitation steps, account information or secrets in public issues. If no private route is available, retain your report until one is provided.

A dedicated monitored vulnerability-reporting address is not currently published. This is a release limitation, not a promise of a response time.
