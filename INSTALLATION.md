# Desktop installation

Windows 10/11 x64 is the current beta target. macOS is planned next; Linux follows. No macOS or Linux downloads exist.

A public verified Windows installer is not available yet. Draft releases are test candidates, not stable releases. Check [Lane's download page](https://lane-staging.onrender.com/download) for public availability.

When a verified release is available:
1. Download it from Lane's download page or this repository's releases.
2. Compare its SHA-256 with the checksum published for that exact filename.
3. Install for your Windows user, then open Lane.
4. Sign into your Lane account in your browser and approve the computer.
5. Connect a marketplace and sign in directly on its website. Complete any verification yourself.

Current test builds are unsigned. Do not bypass Windows security protections. Signing and installation checks must be completed before a stable release.

Automatic updates are not enabled. Install a newer verified version when released. To remove Lane, use Windows Settings → Apps. Disconnect marketplace accounts inside Lane first to remove their local session copies. Uninstalling alone preserves local data to avoid accidental loss.
